# 검사 모듈: 문서+코드 (엔진 없음) 〔DRAFT — 사람 승인 후 DRAFT 표시 삭제〕

> 대회 제출물(기획서·발표자료·데모 코드·영상 대본)용. 게임 엔진이 없으니 `docs/checks/<엔진>.md` 대신 이 파일을 쓴다.
> 층마다 **통과 / 실패 / 못 함** 중 하나. 못 한 걸 통과라 쓰지 않는다 (`docs/conventions/Verification.md`).

## 1층 기계 검사 — 명령을 돌리고 출력 마지막 줄을 인용
- `python3 tools/check_conventions.py` — 엔진 폴더가 없어 이름·폴더 검사는 "못 함" 이 정상. **R13(비밀값)** 만 통과여야 한다.
- 데모 코드가 있으면 그 언어의 실행·테스트 명령 (예: `python3 -m pytest`, `node --test`). 없으면 "못 함(코드 없음)".
- 문서 분량: `wc -m 제출본/*.md` — 요강 글자 수 한도 안인지 숫자로.
- 금지어·개인정보: `grep -nE '[0-9]{6}-[0-9]{7}|010-[0-9]{4}-[0-9]{4}' 제출본/ -r` 결과 0줄.

## 2층 동작 검사 — 실제로 돌려 본 결과
- 데모: 처음 받은 사람 기준으로 README 순서대로 실행 → 화면·출력이 나오는지. 출력 한 줄 인용.
- 문서: 요강 항목표 대조 — 요강의 항목마다 "제출본 어느 절에서 답했는지" 표. 빈 칸이 있으면 실패.
- 링크: 문서 속 URL 을 `curl -sI` 로 열어 200 인지.

## 3층 눈 검사 — 결과물을 실제로 열어 보고 무엇을 봤는지 적음
- PDF·이미지·발표자료는 파일을 열어 페이지 수·첫 장 제목을 적는다.
- 영상은 첫·중간·끝 프레임을 뽑아 본다. 못 보면 "못 함 — 감독".
- 사람 눈 다섯 칸(`PlayerEye.md`)을 심사위원 눈으로 바꿔 읽는다: 처음 보는 심사위원 · 3분 안에 핵심이 보이나 · 요강 양식 · 분야 상식 · 막힘 없음.

## 알려진 함정
- 요강 날짜·상금·자격은 요강 원문에 있는 것만. 모르면 "확인 필요".
- AI 생성물 허용·저작권 조항을 어기면 수상 취소 — 요강 조항을 대조표에 꼭 넣는다.
- 제출·접수·폼 입력은 사람이 한다. 루프는 `제출본/` 파일까지만.
